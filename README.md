### 🛠️ Things I've built in MOM

| | Area | What it does |
|---|---|---|
| 💰 | **Intervention costing** | Standard vs Real cost, anaesthesia, personnel and consumable costs, plus P&L "set target" |
| 🧭 | **Parcours (patient journeys)** | Cost popups, sejour dashboards and synthesis reports for every patient stay |
| 📊 | **Cohort analysis** | Compares two periods with significance tests and **Cohen's d** effect size |
| 🌳 | **Health pathways** | Probability-weighted trajectory costing. Every branch has a %, every path has a price |
| 🤖 | **AI chatbot** | Plain English → SQL with RASA NER, then an **MCP + Mistral** chat with entity pseudonymisation |
| 🔐 | **EIMP encryption** | Patient identifiers become 36-character codes on upload. Same patient, same code, zero leaks |
| 🔄 | **AI-sync** | Syncs SQL templates between hospital sites and the master server, across 4 repos |
| 📑 | **Excel exports** | Migrated everything to excel4node. If it has a "Download" button, I probably touched it |
| 🚑 | **Emergency module** | Emergency master data, importation (with timezone fun 🕐) and exports |
